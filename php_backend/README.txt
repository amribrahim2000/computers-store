====================================================================
  دليل تشغيل وتنصيب برنامج حصر وسجلات أجهزة الكمبيوتر والمستشفيات
  Hospital Computer Inventory System (PHP & MySQL Backend)
====================================================================

أهلاً بك! يتيح لك هذا المجلد تشغيل قاعدة بيانات MySQL برمجية وربط النظام برئاسة قسم IT بالمستشفى.

--------------------------------------------------------------------
الخطوة 1: استيراد قاعدة البيانات (MySQL / phpMyAdmin)
--------------------------------------------------------------------
1. افتح برنامج XAMPP أو لوحة تحكم cPanel الخاصة بسيرفر المستشفى.
2. شغل خدمتي Apache و MySQL.
3. افتح phpMyAdmin في المتصفح على العنوان: http://localhost/phpmyadmin/
4. اضغط على "New" أو "جديد" لإنشاء قاعدة بيانات باسم: hospital_inventory
5. اختر الترميز: utf8mb4_unicode_ci ثم اضغط "Create".
6. اضغط على تبويب "Import" (استيراد)، ثم اختر ملف: database.sql من هذا المجلد.
7. اضغط على زر "Go" بأسفل الصفحة لاكتشاف الجدول وإدراج الأجهزة الافتراضية.

--------------------------------------------------------------------
الخطوة 2: ضبط الاتصال في ملف config.php
--------------------------------------------------------------------
افتخ ملف config.php وعين بيانات السيرفر الخاصة بك:
  $db_host = "localhost";
  $db_user = "root";          // اسم مستخدم قاعدة البيانات
  $db_pass = "";              // كلمة المرور (اتركها فارغة لـ XAMPP)
  $db_name = "hospital_inventory";

--------------------------------------------------------------------
الخطوة 3: تشغيل واجهة المستخدم
--------------------------------------------------------------------
1. يمكنك تحميل تطبيق المطبوعات والتطبيق التفاعلي الكامل بالضغط على زر
   "تصدير حزمة PHP & MySQL" الموجود بالشريط العلوي للموقع.
2. اختر "تحميل كملف مضغوط ZIP" لحفظ جميع ملفات المشروع على جهازك.
3. انقله إلى مجلد htdocs في XAMPP (مثال: C:\xampp\htdocs\hospital_inventory).
4. افتح المتصفح وادخل على: http://localhost/hospital_inventory

بيانات الدخول الافتراضية للنظام:
- المدير: admin / 123
- فني صيانة: tech / 123
- مستعرض: viewer / 123
